# CE-I1 — узел как единица взаимодействия Composite Edit

Статус: **DECIDED** (owner 2026-09-07). Уточнение CE-0 после полевой
обратной связи и аудита `docs/reference_notes/MH_Edit_Interaction_Audit_d3ec999.md`.
Owner разрешил исполнение срезов до снятия legacy-пути CE-6b2.

## Пользовательский контракт

- Правый клик по composite actor открывает его определение. Edit Contents
  ссылки в Composite Outliner открывает определение подкомпозита. Одновременно
  доступно для записи одно определение; опубликованные остальные occurrences
  сохраняют свой вид до Save.
- Клик по любому мешу внутри вложенной ссылки выбирает всю ссылку как узел
  текущего определения. Подсвечиваются все принадлежащие ей меши, соседние
  узлы остаются невыбранными. Для редактирования её внутренних узлов нужен
  явный переход Edit Contents.
- Выбор хранится в сессии по NodeId; компоненты и строки дерева отображают его.
  Активный узел определяет pivot gizmo и Details. Обычный клик заменяет выбор,
  Ctrl переключает участие, Shift добавляет. Box/frustum выбирают авторского
  владельца попавшей геометрии. Родитель и выбранный потомок трансформируются
  совместно один раз.
- Gizmo пишет authored local transform узла относительно effective world
  transform его родителя. Локальная система gizmo берётся у активного узла.
  Движок сохраняет ответственность за W/E/R, snapping и навигацию viewport.
  Непредставимый TRS отклоняется, матрица проверяется до декомпозиции.
  Узлы с генерируемым profile/p2 transform нельзя передвигать обычной командой.
- Один завершённый жест — один Undo; отмена жеста возвращает исходные transforms
  и не оставляет шаг Undo. Esc последовательно отменяет жест, снимает выбор,
  затем предлагает выйти из сессии. Enter не сохраняет определение.
- Enter/Edit switch/Save/Cancel не вызывают фокусировку или перемещение камеры.
  Текущее положение камеры после пользовательской навигации не откатывается.
  F остаётся явной командой пользователя и использует bounds выбранных узлов.

## Граница среза

Вне Edit геометрия продолжает материализоваться через общий ISM-пул уровня.
В Edit используются отдельные временные StaticMeshComponent, а suppression
lease скрывает редактируемое occurrence. Wire v5, resolver/RNG, публикация
и runtime bridge сохраняют существующий контракт.

Пакетная команда transforms и стабильные ID служат общей основой для будущих
создания, дублирования, удаления и подмены узлов. Уже существующие структурные
команды Composite Outliner сохраняются. Native Duplicate/Delete/clipboard
на временных объектах блокируются до подключения соответствующих команд draft.
Расширение клавиатурного дублирования, числовые TRS-поля Details и оптимизация
холодной загрузки не являются acceptance этого среза.

## Проверка

Автоматика проверяет reference pivot, принадлежность визуальных компонентов,
выделение соседей, сохранение ID после структуры/Undo, scaled occurrence,
атомарную валидацию, multiselect с предком и отмену жеста. Полевая проверка
в RHI обязательна для качества подсветки, клавиш мыши, snapping и отсутствия
перехвата камеры. NullRHI не заменяет эту проверку.
