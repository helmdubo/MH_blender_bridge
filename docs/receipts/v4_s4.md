## Реализованный кандидат

1. Добавлен editor-only `FMHProjectResourceIndex` на stock `SQLiteCore`:
   schema `mh.project_index:4`, пять проекционных таблиц, generation,
   транзакционные FullScan/UpsertPaths/GeneratedAssets refresh и
   normalized logical dump.
2. Open fail-closed проверяет integrity, exact `sqlite_master` signature,
   закрытые словари persisted rows и derived-consistency `ResourceKeys`;
   mismatch/аномалия приводит к delete-and-rebuild без migration.
3. Resolver и change detector переведены на indexed lookup. 10k resolve не
   запускает повторный scan; duplicate/invalid/source dependency closure и
   GeneratedAssets precedence применяются до import plan.
4. Dependencies извлекаются из Material/Composite с provenance и закрытыми
   ролями `texture|placement_mesh|placement_composite`; slot-рёбра оставлены
   S5.
5. GeneratedAssets строятся из union Asset Registry query по любому из ровно
   шести `MH.*` tags без загрузки UObject. Валидируются exact-six, carrier,
   deterministic object path, duplicate claims, `source_blocked`, а у binary
   kinds — тождество `AppliedHash == SourceHash`.
6. Добавлен минимальный editor-only `UMHTextureSourceData`; texture import
   сохраняет receipt и публикует шесть tags. Material/Composite получили
   шестой `MH.SourceHash`.
7. Publish Material/Composite после atomic replace выполняет single-shot
   self-publish upsert; успешный import/publish обновляет GeneratedAssets.
   Material receipt откатывается в памяти при package-save failure, новый
   Adopt-carrier удаляется; уже опубликованный source не откатывается.
8. Probable rename использует только биективные `Disappeared × Appeared`
   endpoints одной generation. Move без rename сохраняет identity и даёт
   `NO_CHANGE`; rename даёт unresolved/orphan старого ключа и unique нового.
9. Deprecated `UMHImportLedger`, Ledger composition и commandlet-флаги
   `-ledger`/`-writeledger` удалены без migration/dual-read.
10. Зарегистрированные S4 diagnostics: `MH_W_PROBABLE_RESOURCE_RENAME`,
    `MH_W_ORPHAN_REBOUND_CONTENT_DIVERGED`,
    `MH_E_AMBIGUOUS_GENERATED_ASSET`; golden registry = `45 E / 13 W`.
11. Дивергентный `orphan → rebind` фиксируется только в памяти живого индекса.
    Событие потребляется ровно один раз после успешного сохранения receipt и до
    refresh GeneratedAssets у Material, Composite и вложенных Texture-imports;
    попадает в warnings отчёта операции и Message Log. Обычный `stale` его не
    создаёт; `Close`, рестарт и delete-and-rebuild теряют событие by design.
    `Diagnostics` и normalized dump его не содержат. Pending автоматически
    снимается, если ключ до импорта перестал быть единственным здоровым `stale`.

## Закрытие `OPEN-V4-19`

Временная Diagnostics-persistence удалена. Индекс не открывается и не
пересканируется ради optional warning: если matching live index отсутствует,
импорт продолжается без события. Source-wins rebind идёт обычным `REIMPORT`
без подтверждений. Событие не влияет на rebuild-identity и не может блокировать
операцию.
