# V5-S6.1.2 — collision + phmat транспорт

Статус: **реализован, интегрирован Lead, кросс-проверен на реальном FBX;
не закоммичен**. Дата: 2026-08-30. Норматив —
`docs/15_v5_s6_1_1_hardening.md` §3 (носители §3.4 + ратификация
классификации ролей Lead 2026-08-30). Три исполнителя: D (оверлей-патч
№2 dag4blend), E (Python FBX-транспорт), F (UE collision/phmat) +
интеграция Lead.

## Реализовано

### D. Оверлей-патч №2 dag4blend (установлен, с бэкапом)

«Отдельный текстовый файл» owner-спеки — UI-артефакт (`props_temp`);
фактически script-блок ноды живёт в `obj["dagorprops"]`. Патч (14 строк
в `importer.py`) зеркалит `collision:t`/`phmat:t`/`isPhysCollidable:b`/
`isTraceable:b` в ID-properties того же меша; `:t` без кавычек, экспорт
dag4blend не затронут (его writer читает только dagorprops). Валидация
на реальных laundry-дагах mall_omsky (owner-примеры узлов): 162 объекта,
изменение ровно одно — зеркала у 14 объектов. Установлен;
активен после перезапуска Blender. Архив + README —
`reference/dag4blend_patches/`; бэкап — `backup_installed_20260830/`.
Находки: в CDK есть опечатка `phmat:t="cermic"`; render-ноды тоже могут
нести `collision:t`/`phmat:t` (wires_a) — классификация не по свойствам.

### E. Python-транспорт (writer/parser)

Frozen carrier: FBX user properties Model-узла `mh_collision`
(`phys`|`trace`), `mh_collision_shape` (`mesh|box|convex|capsule`,
default mesh), `mh_phmat` (charset-валидация, незарегистрированный токен
легален). Классификация ролей — ратифицированная: name-токен авторитетен;
при молчащем имени роль определяют `isPhysCollidable:b`/`isTraceable:b`
(ровно один true); противоречие — имя побеждает + warning; ни имени, ни
валидной декларации → распознанный drop с warning. Свойства читаются
claims-механизмом (dagorprops приоритетнее ID props). Транспорт-копии:
все авторские ID-props снимаются на время записи (защита от подделки
`mh_*` и от нерепродуцируемых `str(PropertyGroup)` с адресами памяти),
пишутся только три контрактных ключа; восстановление в `finally`.
Коллизии собираются со всех LOD, вне LOD-грамматики, их слоты — вне
union/closure. **Union стал render-only** (UCX-хвост S6.1.1 закрыт).
`parse_mesh_fbx` возвращает `plan.collision_nodes` (kind/mode/shape/
phmat), enum-нарушения — грамматический отказ.

### F. UE collision + phmat

Carrier авторитетен и читается до name-маркеров
(`MHFbxSceneTranslator`: user-defined `FbxString` на Model в
Properties70). `phys` → Simple Collision: `mesh`/`convex` →
`FKConvexElem` по вершинам, `box` → `FKBoxElem` (node-local AABB),
`capsule` → `FKSphylElem`; все части — элементы одного AggGeom.
`trace` → Complex Collision через нативный
`UStaticMesh::ComplexCollisionMesh`: companion-меш
`/Game/MH/Generated/Collision/<name>_trace` (editor-only, в билд не
тянется, секции по phmat-токенам, создаётся/обновляется/удаляется
импортёром). Резолв `UPhysicalMaterial` по имени токена в настраиваемом
`PhysicalMaterialRoot` (default `/Game/PhysicalMaterials`); отсутствие
токена/ассета — `MH_W_DAGOR_CONSTRUCT_DROPPED`, без отказа.
`MHStaticMeshImporterVersion` 3→4. Ограничения UE 5.7 (задокументированы,
семантика не изобреталась): per-shape физматериал simple-элементов
нативно отсутствует → `BodySetup->PhysMaterial` от доминирующего токена;
per-section phmat complex-коллизии рантайм резолвит через
render-материалы владельца → секции companion'а пока получают движковый
default. **Owner-развилка** (не срочно): (a) нести физматериал на
managed render-MI, (b) домен MI-носителей phmat, (c) оставить как есть.
Рекомендация Lead — (c) для v1, полный контракт — к v2.0.

### Lead-интеграция

- Обновлён S6.1.1-тест warnings-канала (bare-`cls` остаётся распознанным
  drop; phys/trace транспортируются).
- Ратификация классификации ролей записана в док 15 §3.4 (в GAZ только
  2 из 54 коллизий несут name-токен; роли объявляют ратифицированные
  декларации §3.1). Известный round-trip-разрыв paint-only узлов
  задокументирован там же.
- **Кросс-проверка на реальном файле**: сгенерирован настоящий
  `gaz53_b_body.mesh.fbx` (6.4 МБ, 726 узлов) worktree-писателем из
  GAZ-сцены; UE-читатель увидел байт-в-байт то же, что Python-парсер:
  оба коллизионных узла (phys/mesh/steel 205 вершин; trace/mesh/steel
  6715 вершин — **имя без слова trace, вытянут только carrier'ом**),
  union 28 render-only, LOD 0–3 цел; полный импорт 1.4 с: 1 convex,
  companion с секцией `steel`, `GetPhysicsTriMeshData` возвращает ровно
  11 317 треугольников trace-геометрии (точное равенство, не эвристика);
  phmat деградировал в warning — ассетов реестра ещё нет. Главный риск
  формы Properties70 не реализовался.
