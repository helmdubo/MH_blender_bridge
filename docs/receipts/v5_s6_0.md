Большая часть общего diff — переданный документ12, квитанция и сохранённые
исходники evidence, а не дополнительная функциональность:

1. `MHCompositeActor.h`: снят `IsEditorOnly()`, из-за которого primitive proxy
   не отображался в Game View. Обычные компоненты и нативный `HActor`
   сохранены; кастомных hit proxies/raycast нет. `NeedsLoadForClient/Server`
   возвращают false: authoring wrapper не становится runtime-актором.
2. `MHCompositePlacementCompiler.cpp`: leaves прикреплены к существующему
   top-level authoring handle через уже имеющийся `Leaf.RootNodeIndex`.
   Индекс проверяется в preflight до мутаций. Leaves и placeholder roots
   остаются absolute T/R/S; итоговая матрица — прежняя `Leaf.WorldMatrix × Basis`.
   Дети placeholder (box/text) сохраняют относительные трансформы.
3. `MHCompositeLevelSubsystem.cpp`: Build до `CreatePackage`/AssetCreated/publish
   создаёт свежую штатную source/index projection, проверяет source closure
   прямых mesh/composite-ссылок через `IsImportBlocked`, затем вызывает уже
   существующий seed-free `MHProbeCompositeBuildV5` для applied endpoints и
   transforms. Проверяются также невыбранные/zero-weight options и profiles.
4. Companion `MHCompositeRuntimeBridge.cpp`: известные source wrappers
   исключены из gameplay-reference scan через `Sources.Contains(Actor)`.
   Раньше их исключал `IsEditorOnly`; без companion собственный RootComponent
   wrapper ошибочно считался бы внешней ссылкой на него. Внешние ссылки,
   attachment checks, WP/OFPA admission и существующий handoff не ослаблены.

Резолвер, runtime module, формат, подписи, registry, index schema, импортёр,
watcher, FBX, Blender production, Engine, `reference/` и `golden/` не менялись.
Новых diagnostic codes нет: registry остаётся **52 E / 14 W**.
Break не делает refresh/self-heal. Physical-LF guard проверил все 16 tracked
файлов `reference/dagor_fixtures` и `golden/v5`: ни одного CR-байта.

**Не заявляется:** исправление G-off selection после открытия сохранённого
уровня, перенос сборки из PostLoad, полная глубокая semantic hierarchy или
устранение лагов. В main нет handles промежуточных nested group/random nodes;
здесь восстановлена только принадлежность leaves верхнеуровневым handles.
Successful Build по-прежнему может выполнять полный preflight scan и затем
штатный scan импорта. Cache, idempotent assignment, nonblocking pending-mesh,
watcher scope и per-operation lookup в этом срезе отсутствуют.
