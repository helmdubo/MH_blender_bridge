   attachment checks, WP/OFPA admission и существующий handoff не ослаблены.

**Известное следствие для S7 / World Partition.**
`NeedsLoadForClient/Server=false` не заменяет editor-only классификацию WP.
Descriptor мог создаваться и раньше: `AActor::CreateActorDesc` и external-save
путь не требуют `IsEditorOnly=false`. Конкретно меняется
`FWorldPartitionActorDesc::bActorIsEditorOnly`: `Init` берёт его непосредственно
из `Actor->IsEditorOnly()` и сериализует (`WorldPartitionActorDesc.cpp:148,808`
stock UE5.7.4). Streaming generation фильтрует loaded actor / unloaded descriptor
по этому признаку, не по `NeedsLoadForClient/Server`
(`WorldPartitionStreamingGeneration.cpp:852–883`). Поэтому S7 должен явно учесть
descriptor/streaming classification при замене authoring placements. Это само
по себе не доказывает попадание editor-класса в packaged build: поздние cook/load
фильтры отдельны. Текущий bridge продолжает fail-closed блокировать WP и OFPA
до handoff (`MHCompositeRuntimeBridge.cpp:277–288`), включая unloaded WP placements.
WP acceptance не заявляется; независимый агент только читал stock Engine.

Резолвер, runtime module, формат, подписи, registry, index schema, импортёр,
watcher, FBX, Blender production, Engine, `reference/` и `golden/` не менялись.
Новых diagnostic codes нет: registry остаётся **52 E / 14 W**.
Break не делает refresh/self-heal. Physical-LF guard проверил все 16 tracked
файлов `reference/dagor_fixtures` и `golden/v5`: ни одного CR-байта.

**Не заявляется:** исправление G-off selection после открытия сохранённого
уровня, перенос сборки из PostLoad, полная глубокая semantic hierarchy или
устранение лагов. В main нет handles промежуточных nested group/random nodes;
здесь восстановлена только принадлежность leaves верхнеуровневым handles.
Successful Build по-прежнему может выполнять полный preflight scan и затем
штатный scan импорта. Cache, idempotent assignment, nonblocking pending-mesh,
watcher scope и per-operation lookup в этом срезе отсутствуют.
