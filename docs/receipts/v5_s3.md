## Выполнено

### Typed Blender authority и Options UI

1. `Object.mh4blend` является единственной authority для `kind`, `weight` и
   `option_index`. ID properties `mh_composite_kind`, `mh_random_weight` и
   `mh_random_option_index` поддерживаются как однонаправленное диагностическое
   зеркало; reader/writer их не читает, typed state всегда побеждает.
2. Random-node и options представлены Empty-объектами. Option resource задаётся
   `instance_collection`; weight/index никогда не записываются в resource
   Collection. Попытка принести их туда блокирует export.
3. Options UI реализует Add/Remove/Up/Down/weight. Reorder меняет два explicit
   index, remove не перенумеровывает остаток. Missing/negative/duplicate index,
   invalid kind/weight и all-zero weights остаются наблюдаемыми и блокируют
   ресурс; silent clamp/repair отсутствует.
4. Option transform display-only и не влияет на canonical bytes. Ordinary
   children random-узла не смешиваются с options; option вне выбранной resource
   Collection блокируется fail-closed.
5. Addon registration не мутирует `.blend`. Явная materialization создаёт и
   использует ровно четыре служебные сцены: `COMPOSITE`, `MESH`,
   `ACTOR_PLACEHOLDERS`, `TECH`. `TECH` не получает source-authority resources.
6. Seed/InstanceSeed не добавлен ни в RNA, ни в operators/panels, ни в custom
   properties; отдельный static gate проверяет весь `addon/mh4blend`.

### Оба Dagor→MH входа

1. Добавлен строгий Blender-free parser `*.composit.blk`: source-order graph,
   explicit `name:type`, `ent`, implicit/explicit weight, raw 3×4 matrix и
   полная provenance. Unknown/missing type и lossless-непереносимые конструкции
   блокируются; `include`/`p2` дают явный `STOP OPEN-V5-9`.
2. Direct importer глобально проверяет canonical physical identity и ambiguity
   root/dependencies, рекурсивно читает все существующие composite dependencies
   через обычные children и все random options. Missing mesh/composite остаются
   lossless placeholders; ambiguous same-kind блокируется.
3. Dagor Y-up matrix конвертируется exact basis conjugation в Blender Z-up,
   затем local и composed-world matrices проходят owner-frozen 8-ULP float32
   TRS predicate. Shear блокируется `MH_E_UNREPRESENTABLE_TRANSFORM` до Blender
   mutation с полной causal ancestry, resource names и file/line/NodePath.
4. Уже импортированная dag4blend-сцена поддерживает оба random-сигнала:
   helper Collection `random.*` либо `type:t == "random"`. Weight cascade:
   `dagorprops['weight:r']` → ID `weight:r` → ровно `1`.
5. Options поднимаются из helper Collection в typed direct children; helper и
   `TECH_STUFF` не становятся authority. Explicit `type/name` обязателен,
   угадывание по Blender name запрещено.
6. Nested dag4blend composite Collections рекурсивно конвертируются в DTO
   documents; opaque composite override запрещён, поэтому all-options closure и
   cycles видимы общему валидатору. Mesh Collection допустим только как exact
   identity-checked override; actor transport Collection не становится MH
   authority — token получает canonical placeholder в `ACTOR_PLACEHOLDERS`.
7. Shared `materialize_composite_documents` выполняет полный occupied-ID
   preflight и один `MeshImportTransaction`. External links журналируются LIFO;
   injected failure на втором route удаляет первый link и все новые datablocks.
   Scene reveal после commit best-effort и не меняет успешный receipt на error.
8. UI предоставляет отдельные операции для authoritative `.composit.blk` и
   уже открытой dag4blend Collection; import-mode/reuse controls не добавлены.

### GAZ и field round-trip

Owner GAZ closure читается прямо из `reference/dagor_fixtures/gaz53/`:

- обнаружены `gaz53_b_random_cmp`, `gaz53_b_body_cmp` и
  `gaz53_body_bc_random_cmp`;
- реальный random-node материализует ordered composite options
  `gaz53_bread_b_cmp`, `gaz53_wooden_b_cmp`, `gaz53_wooden_c_cmp` с весами
  `1,1,1`;
- missing definitions остаются видимыми typed placeholders;
- все три converted documents экспортируются в temp source root и дают exact
  `composite_json_bytes` соответствующих DTO. Option display transform и
  diagnostic mirror edits canonical bytes не меняют.
