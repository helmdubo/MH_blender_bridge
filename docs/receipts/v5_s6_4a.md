## 2. Реализация

Добавлена dockable Nomad Tab `MH Composite Outliner` в группе Level
Editor меню Window. Панель активна только в editor-процессе и состоит
из двух частей:

- верхнее source-дерево выделенного `AMHCompositeActor`;
- нижние read-only секции `Entities`, `Children`, `Node`.

Source-модель вынесена из Slate в `FMHCompositeOutlinerModel`. Она:

- строит canonical `NodePath` из persisted pre-order
  `UMHCompositeAsset::Nodes` и `ParentIndex`;
- различает mesh, composite, random, group, gameobj и actor;
- добавляет варианты random отдельными строками и показывает empty как
  `--`;
- лениво загружает только раскрываемый nested composite;
- fail-closed отклоняет неверный parent index, цикл и несовпадение
  logical identity nested asset;
- накладывает `Nodes`, `Leaves` и `Decisions` resolved-плана без
  изменения source или плана;
- сохраняет source row identity при `RefreshOverlay`.

Resolved overlay показывает выбранный random option, sampled local TRS
в tooltip и красный missing materialized endpoint. Если plan отсутствует,
source-дерево остаётся доступным, а в шапке показывается точный
`LastPlacementError`.

Контекст строки содержит только навигацию:

- `Open Asset` для managed composite;
- `Browse to Asset` для разрешённого generated asset;
- `Copy Name`;
- `Copy Source Filepath` по receipt `SourceRelativePath` относительно
  настроенного Source Root;
- `Reveal in Explorer` для каталога source document.

Кнопки `+`, Insert, Remove, Add params, Save, Reset и любые другие
mutation affordances не создавались.

## 3. Синхронизация и обновление

Строка с существующим placement component выбирает этот компонент через
штатный editor selection API. Обратное направление слушает штатное
component selection и находит строку по уже существующему placement
component/NodePath. Custom hit proxy не добавлялся.

Панель слушает `OnActorSelectionChanged`, `OnComponentsEdited` и
selection delegates; polling отсутствует. После успешной установки
нового resolved plan actor посылает существующий
`BroadcastComponentsEdited`. Если compiler уже послал это событие из-за
изменившегося component array, повторный broadcast подавляется. Slate
listener объединяет события и обновляет модель на следующем active tick,
то есть overlay не входит в измеряемый путь reseed.

Performance probe: 300 source rows, 200 вызовов `RefreshOverlay`, среднее
`0.323194 ms`, порог `<1 ms`, `deferred_from_reseed=1` — **PASS**.

## 9. UI-решения вне автотестов

1. Панель зарегистрирована как Nomad Tab в Level Editor category, а не
   как новый asset editor: она инспектирует выбранное размещение в
   текущем мире.
2. Missing endpoint красит icon и label; selected option — зелёный.
   Это сохраняет читаемость при одновременном overlay и diagnostic.
3. Details используют текстовые строки, а не disabled controls, чтобы
   S6.4a не обещал будущие команды S6.4b.
4. Lazy expansion выполняется в `OnGetChildren`; viewport navigation
   раскрывает только composite borders целевого NodePath.
5. Reveal открывает содержащий source-каталог; изменение файлов из
   панели невозможно.
