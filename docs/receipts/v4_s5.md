## Реализованный кандидат

1. Добавлены общий `FMHSceneIR`, единый классификатор узлов и direct FBX SDK
   translator. FBX читается из захваченных bytes; проверяются canonical
   axis/units, типы узлов, parent closure, циклы, маркеры, dense LOD и subset
   material slots. FBX не обязан содержать MH metadata.
2. Translator переносит evaluated global/geometric transforms, позиции,
   normals, UV0, polygon material indices и material slots. Зеркальность
   FBX→UE учитывается явным winding; singular/sheared socket transform и
   прочие невыразимые transport-состояния блокируются
   `MH_E_FBX_TRANSPORT_FAILED`.
3. `FMHStaticMeshBuilder` выполняет полный in-place rebuild того же
   `UStaticMesh`: все LOD, slots/MI, sockets и `BodySetup`. Для каждого
   collision-node создаётся ровно один convex hull; режимы
   Query/Physics задаются по §4, decomposition и auto-collision отсутствуют,
   degenerate hull блокируется.
4. Материалы резолвятся до сборки по logical slot name. Принимается только
   managed MI с согласованным material receipt и актуальным raw hash;
   отсутствие/несогласованность даёт
   `MH_E_UNRESOLVED_MATERIAL_REFERENCE` и блокирует mesh.
5. Добавлен `UMHStaticMeshImportData` с ровно пятью owner-полями:
   `LogicalName`, `SourceRelativePath`, `SourceHash`, `ImporterVersion`,
   `bLocallyModified`. Публикуются ровно шесть `MH.*` tags, для binary kind
   `MH.AppliedHash == MH.SourceHash`.
6. При совпадении raw hash и importer version получается `NO_CHANGE`; смена
   source-relative path обновляет только receipt; смена importer version или
   bytes запускает полный rebuild. Явный Reimport всегда пересобирает и
   предварительно проверяет identity вызывающего UObject.
7. Editor hook ставит persisted `bLocallyModified` при изменении mesh, socket
   или BodySetup вне controlled apply. Следующий import выдаёт
   `MH_W_MANAGED_STATIC_MESH_LOCALLY_MODIFIED`, source-wins пересобирает asset
   и сбрасывает флаг только после успешного apply+save.
8. Applied state коммитится одним package save после geometry build. При
   ошибке save старый receipt восстанавливается; новый несохранённый asset и
   его точный package удаляются. Snapshot source повторно сверяется до commit.
9. Project Index теперь парсит `static_mesh`, сохраняет точные dependency
   tuples `static_mesh → material` с ролью `slot`, применяет dependency
   closure и проецирует mesh claims в GeneratedAssets. Import coordinator
   выполняет material → mesh → composite.
10. Возвращён mapper-facing commandlet `MHFbxDump` поверх того же SceneIR:
    формат `mh.fbxdump:4`, summary/full режимы, stable captured bytes и
    атомарный safe report под `Saved/Mimir`.
11. Зарегистрированы `MH_E_FBX_TRANSPORT_FAILED` и
    `MH_W_MANAGED_STATIC_MESH_LOCALLY_MODIFIED`; golden registry =
    `46 E / 14 W`. Старый незарегистрированный
    `MH_E_GEOMETRY_SOURCE_MISMATCH` отсутствует.

## Acceptance и regression coverage

Новые UE Automation tests покрывают:

- classifier: valid hierarchy, marker/type rejects, parent/cycle failures,
  dense LOD и slot subset;
- full builder replacement LOD/geometry/slots/sockets/collision в том же
  UObject;
- exact receipt, шесть tags и local-edit hook для mesh/socket/BodySetup;
- реальный plain FBX, созданный FBX SDK без MH metadata: LOD0/LOD1, managed
  material slot, UCX/`_cls_*`, socket, deterministic asset path;
- equal-hash `NO_CHANGE`, затем изменённый FBX с полной заменой всех доменов
  в том же UObject, warning локальной правки и сброс флага;
- точное `slot`-ребро индекса, reload из SQLite и транзитивную блокировку при
  пропавшем материале.

Независимые read-only аудиты transport/classifier и receipt/import lifecycle
нашли и помогли закрыть до финальных gates: mirrored winding, missing material
layer при нескольких slots, невыразимый socket shear, двухфазный save,
unmanaged MI, stale receipt path, identity explicit Reimport и local edits
socket/BodySetup.
