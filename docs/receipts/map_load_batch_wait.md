# Квитанция — батчевое ожидание компиляции мешей (U0a)

Дата: 2026-08-31
Ветка: `perf/definition-batch-compile-wait`
Исполнитель среза: Lead
Статус: **READY FOR OWNER FIELD TEST (загрузка карты)**

## 1. Полевой дефект

После появления полного коттеджа (729 мешей) загрузка карты выросла ~10×
и «замирает» с неактивными CPU/памятью. Механизм: definition build на
map load ждал компиляцию каждого меша **по одному**
(`FinishCompilation({Mesh})` внутри обхода графа) — до 729
последовательных стойл главного потока, особенно жёстких при холодном
DDC (после реимпорта v5) и задушенном бюджете async-компиляции.

## 2. Реализация

`MHCompositeResolvedPlan.cpp`, `FAppliedPlanBuilder`: two-pass. Проход
графа загружает меши и обрабатывает материалы (слоты — обычная
структура, читаемая во время компиляции), а registry-tag admission меша
откладывается в `FinalizeDeferredMeshes()`: один батчевый
`FinishCompilation` на всё замыкание, затем полная receipt-валидация
каждого отложенного меша. Ни одна проверка не ослаблена — изменён только
порядок: все ожидания склеены в одно.

## 3. Гейты

| Гейт | Результат |
|---|---|
| Guarded UE build | **Succeeded** |
| Полный NullRHI + `-MHGoldenRoot` | **163/163, 0 failed** (включая lifecycle/definition/preview-defects тесты admission компилирующихся мешей) |

Перф-срез с сохранением семантики под существующими гейтами; отдельный
red-тест не строился (см. §2 — поведение эквивалентно, меняется только
число стойл).

## 4. Полевой протокол owner

1. UE-плагин переустановлен; перезапустить редактор.
2. Поднять бюджет async static mesh compilation (Project Settings →
   Editor → Performance) — U0b, см. лог «оценка ~1.1 ГБ при лимите
   0.6–0.7».
3. Загрузить карту. Первая загрузка после реимпорта всё ещё компилирует
   меши (холодный DDC) — но одним параллельным батчем вместо 729
   последовательных ожиданий; последующие загрузки — без компиляции.

## 5. Следующий срез (U0c, отдельно)

Lazy startup: map load вообще без definition build + дешёвый
freshness-отчёт в Message Log («N ресурсов устарели — запустите Import
Changed»), тяжёлая работа только по явному действию пользователя.
Ратифицировано owner 2026-08-31 («динамическая/ленивая/ручная
индексация»).
