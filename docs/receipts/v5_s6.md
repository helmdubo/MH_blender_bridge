## Реализация и границы

- `AMHRuntimeCompositeActor` находится в runtime module. Persisted вход —
  копия полного seed-free графа и hard UObject references всех source
  dependencies, плюс placement Seed. Резолвер тот же
  `MHResolveCompositePlan` / `mh.random_resolver:2`; stream остаётся
  `mh.random_stream:1`. Второго RNG или resolver нет.
- Внутренний бинарный транспорт сериализует float32-биты и ordered arrays
  дословно, map keys сортирует. Reject: неизвестный internal tag, duplicate key,
  invalid UTF-8, truncation/trailing bytes, malformed graph, missing/cyclic
  closure, неполный либо editor-only endpoint binding. Это не новый source
  format, не wire JSON и не замена frozen canonical-векторов.
- Значения profile raw hashes копируются в graph metadata для прежнего closure
  hash. Сам private `FMHPlacementProfile.AppliedSourceHash` остаётся
  editor-only: ни carrier-типа, ни source receipt, ни нового тега/индекса в
  runtime не появляется.
- Actor tokens не имеют source raw hash. Их hard UClass bindings собираются
  отдельно из ТОГО ЖЕ source graph по всем options, включая zero-weight.
  Source closure / signatures от этого не меняются.
- Cold-loaded static mesh может ещё компилироваться: UE временно возвращает
  registry tags до inherited provider, скрывая все шесть MH-тегов корректного
  persisted receipt. Applied adapter теперь завершает async compilation
  ТОЛЬКО этого closure member перед прежней live-tag проверкой. Условие шести
  тегов не ослаблено; диагностике добавлены конкретные поля.
- Общий 8-ULP predicate и placement-matrix admission физически перенесены из
  Editor в Runtime без смены алгоритма. Полный matrix product остаётся рядом
  с frozen `WorldTrs`, не входит в signature preimage.
- Spawn читает только plan leaves. Полные endpoints/matrices проверяются до
  мутации. Ошибка сохраняет старые компоненты; проверяются регистрация
  staged components и фактическое создание gameplay child actor.
- Editor→PIE/cook handoff делает временные runtime siblings. Authoring map
  остаётся с прежними editor placements, source refs, Seed и transform;
  новых persisted companion actors/authority нет. Cook overlay снимается
  после save с восстановлением Actor arrays и dirty flags. В PIE меняется
  только дублированный мир, до BeginPlay.
- Cook/PIE не производят editor preview. Runtime не читает source tree,
  SQLite, Asset Registry или editor settings. SQLite plugin dependency
  ограничена Editor target.
- Неподдержанные World Partition/OFPA placements, attachments и внешние
  reflected level references блокируют handoff с конкретными именами.
  Автоматического переписывания level references нет. Не заявляется поддержка
  произвольных native Serialize-only/GUID bindings внешних gameplay-систем;
  World Partition/OFPA и flattening — отдельный V5-S7.
- Thumbnail renderer/guard не менялись. `reference/`, `golden/`,
  frozen RNG/resolver код и Blender production не менялись.
- Новых diagnostic codes нет: прежние **52 E / 14 W**.

## Делегирование и исправленные findings

Отдельные subagents отвечали за runtime input, editor/cook boundary audit и
пятисторонний parity harness. Основной агент — runtime actor, интеграция,
гейты и финальная проверка. Независимый аудит выявил: unchecked child spawning,
ложный типовой успех `False == 0` в report verifier, отсутствие package-veto
у harvest archive, cleanup незапустившегося PIE. Findings исправлены либо
честно отражены в границе cook ниже.

Промежуточные неуспешные прогоны не являются acceptance:
двойной InitializeNewWorld в новом test fixture (убран); UE_LOG if/else macro
в host runner (добавлены braces); private archive accessor (заменён публичным
save data API); StrictIncludes обнаружил отсутствовавший `UObject/Package.h`
в новом bridge test. Повтор full suite в host с уже persisted parity assets
конфликтовал с S5 transient fixture — regression и cook hosts разделены,
принятые S5-тесты не ослаблялись.

Первый cold cook воспроизвёл `MH_tags=0` при правильных path/hash полях,
в том числе на новом cook host: объяснение старым содержимым стенда для
ЭТОГО отказа отвергнуто. Исправлен async barrier выше. Затем cold PostLoad
восстановил `WorldGridMaterial` в тестовой cube: fixture теперь удаляет
material slots и их source-description associations, перестраивает геометрию
и только потом ставит frozen receipt. Это исправление host visualization
payload, а не добавление material в frozen graph.
