## Выполнено

### Общий контракт и diagnostics

1. Реализована закрытая grammar Composite: корень `nodes`, точные поля по
   `mesh|actor|composite|group`, обязательный/запрещённый `resource`, значимый
   порядок узлов, вложенные `children`, identity-default transforms и
   детектирование duplicate JSON keys.
2. Python и UE используют одинаковые canonical bytes: UTF-8, LF и финальный
   LF, indent 2, фиксированный порядок полей, float32 shortest. Quaternion
   нормализуется и получает канонический знак; non-finite, invalid scale и
   invalid norm блокируются точными машинными кодами. Общий fixture —
   `golden/composite_v4_vectors.json`.
3. Зарегистрированы `MH_E_COMPOSITE_GRAMMAR`, `MH_E_COMPOSITE_CYCLE`,
   `MH_E_UNRESOLVED_COMPOSITE_REFERENCE`, `MH_E_INVALID_NODE_MARKERS`,
   `MH_E_IMPORT_TARGET_OCCUPIED` и
   `MH_E_UNRESOLVED_MATERIAL_REFERENCE`. Legacy Composite diagnostics и пять
   отменённых S2 warning codes удалены. Итоговый registry: `44 E / 10 W`.
4. `core/transforms.py` переписан под §6: Blender конвертирует placement в
   UE centimeters/axes/FQuat, UE компилятор читает canonical transform без
   дополнительной конверсии.

### Blender mesh import

1. Общий API `import_mesh_fbx` выполняет стадии 0–4 из 08 §4.1: собственный
   FBX parse/preflight, общий marker/classifier, материализация `.material`
   до геометрии, пинованный `io_scene_fbx` в staging collection, slot binding
   по parse-truth и реструктуризация обычного ресурса либо `.lods`/aux.
2. Оператор `Import Mesh FBX` зарегистрирован как один Blender undo-step.
   Любой сбой откатывает полную дельту objects/collections/meshes/materials/
   images и вспомогательных datablocks; caller transaction позволяет Composite
   импортёру включить mesh definitions и placements в тот же rollback boundary.
3. Preflight fail-closed проверяет occupation, literal Blender ID names,
   parent closure/cycles, пустые и дублированные Geometry names, material и
   texture dependencies, ordered slots, LOD hierarchy и закрытые marker rules.
   `SOCKET_` с любым ребёнком, двойные markers, payload на Null и shared linked
   Geometry блокируются до записи/мутации. Repair, truncation и `.NNN`
   auto-rename не принимаются.
4. FBX writer зеркалирует classifier, валидирует material slots всех
   транспортируемых MESH, включая collision, и не публикует FBX, который
   собственный reader затем отвергнет.

### Blender Composite

1. Реализованы atomic writer и transactional importer. Writer делает полный
   extract, dependency/cycle preflight, canonical encode, sibling tmp,
   read-back и `os.replace`; diff не вычисляется.
2. Mesh/composite closure резолвится прямым сканом source-дерева. Candidate
   source подменяет старый root при cycle-проверке, поэтому self/ancestor
   cycles и unresolved mesh/composite блокируются до publish. Actor token
   сохраняется lossless и намеренно не резолвится в Blender.
3. Каждое уникальное mesh definition импортируется один раз; placements
   строятся collection instances поверх общего mesh API. Source transforms
   являются world transforms. Композит не содержит и не принимает material
   overrides.

### UE 5.7 Editor plugin

1. Добавлены Editor-only `UMHCompositeAsset`, strict protocol codec,
   importer/publisher и compiler. `ActorClassRegistry` резолвит actor tokens;
   mesh/composite/actor unresolved и composite self/ancestor cycles блокируют
   ресурс.
2. Compiler строит реальные Scene/StaticMesh/ChildActor components. Все
   top-level nodes прикреплены к synthetic Actor root, вложенные authored world
   transforms сохраняются, а display-only `name` не используется как UObject
   identity. Failure удаляет и authored components, и только что созданный
   synthetic root, не трогая pre-existing caller root.
3. Import сначала выполняет closure/preflight и transient compile probe, затем
   повторно сверяет source generation, применяет asset и только после save
   коммитит receipts. Source race не оставляет package/Asset Registry ghost и
   не продвигает applied state.
4. `SourceHash` хранит raw source hash, `AppliedHash` — hash canonical live
   extract. Локальная правка определяется свежим extract; source-wins import
   выдаёт warning. Publish делает live extract → canonical bytes → atomic
   replace → receipt commit.
5. Asset Registry содержит ровно пять нормативных тегов: `MH.Kind`,
   `MH.LogicalName`, `MH.SourcePath`, `MH.AppliedHash`, `MH.Managed`.
