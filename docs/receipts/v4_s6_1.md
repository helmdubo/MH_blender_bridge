  `OPEN-V4-24` в `docs/QUESTIONS.md`.

## Что сделано

- Удалён временный fail-closed запрет `Break` для `group` с ненулевым
  transform. `group` теперь растворяется как структурный pivot, а transform
  каждого дочернего placement применяется как document-world значение без
  умножения на transform группы.
- Automation-регрессия фиксирует определяющий пример: translation группы
  `100`, translation ребёнка `125` — после `Break` актор находится в `125`,
  а не в `225`.
- Blender composite writer проверяет `matrix_world` каждого изменённого
  placement: матрица должна восстанавливаться из собственной T/R/S-декомпозиции
  в float32-допуске. Shear блокирует публикацию
  `MH_E_INVALID_RESOURCE_SOURCE`, а diagnostics содержит имя объекта.
- bpy-регрессии покрывают прямую shear-матрицу и повёрнутого ребёнка под
  родителем со scale `(1, 2, 1)`; при отказе `.composite` не создаётся.

Опциональный UX из owner-решения — drag группы в UE Edit-режиме с явным
распространением дельты на потомков — в микро-срез не включён: обязательный
document-world контракт уже реализован, а дополнительное поведение редактора
требует отдельного UX-решения.
