## Реализация

### Один applied-only plan

`AMHCompositeActor` хранит единственный int32 `Seed`, `bAutoSeed` и
read-only transient `ResolvedSignature`. Auto-create и обычный duplicate
дают новый non-zero seed; ручной 0 допустим. Keep/Lock отключают auto-seed
на duplicate, явный Reseed остаётся доступен. PIE duplication сохраняет seed.

Новый applied-graph adapter собирает input из уже применённых UAssets:
composite document, приватных inline profile receipts, mesh slot tokens,
material local texture overrides и texture receipts. Он не читает source
файлы и не делает scan. Все options, включая zero-weight/невыбранные,
участвуют в admission/closure. Root и nested references проходят одинаковые
проверки unique generated claim, canonical generated path, live receipt и
шести тегов. Missing/invalid/duplicate claims и расходящиеся inline profiles
не получают выдуманный hash, частичный canonical plan или подпись.

Единственная materialization-цепочка:

`applied graph → MHResolveCompositePlan → immutable FMHResolvedCompositePlan → preview / Break / Choices / Trace`.

Старый второй component-spawner `MHCompileCompositeV5` физически удалён.
`MHProbeCompositeBuildV5` оставлен только как документированный seed-free
alias полного source-closure admission: он не создаёт мир/актор/компоненты
и не назначает определению неявный seed.

Plan дополнен полными world matrices, NodePath/provenance и authored-root
metadata. Полные матрицы накапливаются parent-local, до component mutation
проверяются существующим predicate 8 float32 ULP. Geometry consumers и UI
используют эти матрицы; существующий `WorldTrs` в замороженном signature
preimage сохранён для побайтовой совместимости S1/S1.1. RNG/tag/алгоритм
подписи и golden bytes не менялись.

### Seed updates и операции

- import/publish вычисляет `None | ChildSeedsOnly | Transform | Topology`;
  classification не входит в canonical extract, hashes или шесть тегов;
- Seed-only update использует cached applied graph, без повторной загрузки
  source/asset closure. Для plan без draws/decisions обновляется только
  signature. Визуальный `None` с mandatory draws всё равно обновляет trace;
- компоненты сопоставляются по stable plan provenance; неизменённые сохраняют
  указатели, transform-only не пересоздаёт topology, изменённые leaves
  заменяются адресно. Geometry-мутация начинается после admission всего plan;
- actor move обновляет только basis, не Seed/trace/signature; отдельный
  basis-rejection не может восстановить старый plan после отказа **новой**
  definition;
- dependency notify пересобирает plan из applied assets без пересохранения
  уровня. Неизвестная/сломанная closure блокирует plan/Break с диагностикой;
  last-good view — только diagnostic presentation, не новый результат;
- Break читает cached plan, preflight выполняется для всего выделения до
  spawn. Mesh/gameplay leaves материализуются полностью, groups/nested
  composites растворяются; source/asset не меняются;
- Edit использует authored handles, не sampled transforms. Placement move
  не превращается в source edit. Изменённый authored document даёт prospective
  canonical bytes/hash только внутри working graph; applied receipts остаются
  нетронутыми. Commit flush-ит pending edit и публикует тот же admitted
  document без повторной world→local декомпозиции. Cancel возвращает applied
  plan; прежняя необратимая source/Undo-граница сохранена.

Контекстное меню: Reseed, Copy/Paste Seed, Lock/Unlock Seed, Keep Seed on
Duplicate, Show Resolved Choices, Show Decision Trace. Multi-selection:
Individual — каждому свой новый seed, Equal — один новый всем. Clipboard
принимает только полный decimal int32. Stale selection/активный Edit
блокируют изменение до транзакции. Операция seed — один undo step; отказ
нового plan явно диагностируется, без обещания скрытого rollback seed.

## Независимая проверка и найденные дефекты

Задействованы отдельные subagents: applied-graph/architecture audit,
plan metadata и actor regression tests, seed menus/Break и source-compiler
cleanup. Финальная интеграция и гейты выполнены основным агентом.

Исправлены findings независимого аудита с регрессионными тестами:

1. Move больше не оживляет old cached plan после shear-отказа новой definition.
2. Root не обходит duplicate/invalid receipt admission.
3. Abstract/deprecated/reinstanced actor class отклоняется общим predicate
   до preview/Break; проверяется и невыбранная option.
4. Edit отслеживает actor basis; prospective hash и Commit используют один
   admitted source document, без мутации applied receipts.
5. Display-only имена с punctuation/Unicode не используются как UObject
   component names. Ошибочный Copy Seed больше не сообщает об успехе.

Первые regression-прогоны были промежуточными: обновлены старые fixture
receipts/структурные ожидания, исправлены диагностический prefix Break,
OR-семантика FARFilter в тесте и ожидание полного фактического TRS вместо
идеализированной координаты. Production rounding/snapping не вводилось.
StrictIncludes выявил отсутствовавший прямой include `AssetData.h`;
добавлен. Отдельный промежуточный link получил LNK1104 из-за слишком раннего
запуска Automation с загруженной DLL; он не засчитывается как gate.
