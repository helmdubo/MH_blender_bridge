## Выполнено — норматив MH

1. Добавлен bpy-free executable reference `tools/mh_random_reference.py`:
   uint64 splitmix state, int32 seed bit-cast и initial mix, high-32 draw,
   `u32 * 2^-32`, ordered float64 weighted selection со строгим `>`, один
   selection-draw даже для единственной положительной option.
2. Реализован typed placement-profile sampling. Отсутствующее поле draw не
   потребляет; порядок: selection → offset X/Y/Z → rotation X/Y/Z → uniform →
   vertical → children. Sample вычисляется во float64 и сужается до float32;
   применение над authored local T/R/S соответствует §13.2, включая
   `qZ*qY*qX`, authored×sample rotation и scale `(u,u,u*v)` по UE Z.
3. Один `resolve_composite()` сначала строит seed-free source closure по ВСЕМ
   options с cycle reject, затем выдаёт immutable plan: decisions, полный draw
   trace, leaves с parent-local world T/R/S и origin NodePath,
   SelectedDependencies и ResolvedSignature.
4. Source closure поддерживает транзитивные leaf dependencies
   mesh→material→texture, сортирует ресурсы по `ResourceKey.ToString()` и
   хэширует конкатенацию raw hash strings BLAKE3-160. Seed в API closure
   отсутствует.
5. Прообраз `ResolvedSignature` — canonical JSON §13.3 с float32-shortest и
   финальным LF; quaternion canonicalization перенесена из v4 (W, затем XYZ для
   half-turn); display names/paths в подпись не входят.
6. `golden/v5/random_stream_1_vectors.json` фиксирует для seed set
   `{0,1,2,42,123,1024,2147483647}`: 16 raw draws, normalized units, ordered
   decisions, profile draws/samples, world transforms, NodePaths, selected deps,
   signature preimages и signatures. Synthetic graph содержит nested random,
   zero-weight unselected option, single-positive option, full и partial
   profiles, а также parent-local `100 + 25 = 125`.
7. В `requirements-dev.txt` закреплён пакет `blake3>=1.0,<2`; known empty
   BLAKE3-160 vector проверяется отдельным тестом.

## Dagor parity probe — измеренный факт отдельно от норматива

transform ranges, source-derived vectors, runtime observation template и

### Source-derived факт

Проверен публичный `GaijinEntertainment/DagorEngine` exact commit
`75723669297e48e200a0dc67b18c1629e0975daf`:

- PRNG source:
  `prog/gameLibs/publicInclude/gameMath/objgenPrng.h`, symbols
  `objgenerator::rnd/frnd`;
- composite source:
  `prog/tools/sceneTools/daEditorX/services/compositMgr/compositMgrService.cpp`,
  symbols `Component::selectEnt`, `getTm/getRandom`.

Pinned source использует 32-bit LCG и 15-bit normalized sample, а не frozen
splitmix64/high-u32. На равновесном probe selected option уже расходится с
`mh.random_stream:1` для seeds `0, 2, 123, 1024, 2147483647`; совпадает только
для `1` и `42`. Следовательно, byte identity текущих stream primitives ложна.
Исходный код в репозиторий не копировался; добавлена независимая минимальная
source-derived модель и exact provenance.

Pinned C++ передаёт один изменяемый seed нескольким function-call arguments;
по одному source нельзя объявить portable axis binding transform draws.
Golden сохраняет две иллюстративные, не исчерпывающие left-to-right и
right-to-left source candidates и честно требует runtime observation.
