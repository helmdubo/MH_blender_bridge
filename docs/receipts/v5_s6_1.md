### Реализовано

- Три существующие команды читают MH либо dag4blend через строгий dispatcher.
  Частичная/смешанная identity запрещена и на root, и внутри замыкания.
  Даговский reader строит те же Composite DTO; используется тот же S4 staging,
  read-back и ordered publisher. Нового публикатора нет.
- Удалены обязательные materialize, relink, adoption, будущий Blender ID
  preflight и stamping. Direct export не вызывает Blender finalizer.
  Optional Convert остаётся отдельно; external relink теперь только по
  явной галочке, по умолчанию false.
- Режимы root_only / composite_closure / include_all, source-backed
  исключённые зависимости, exact canonical-JSON reuse и unloaded source reuse.
  Существующий JSON не заменяется, если его байты равны. Root может быть
  reused; all-reuse батч не делает ни одного replace, но ревалидирует source.
- Новый `marker`: Python/C++ parse/write, native Blender kind, обычный и
  random-вариант. Сохраняются имя/TRS/выбор; marker не является resource key,
  не требует файла или ActorClassRegistry, не создаёт leaf/actor.
  Существующие actor leaves по-прежнему исполняются по прежнему контракту.
  В C++ enum значения добавлены в конец, прежние binary ordinals сохранены.
- Производные `Nodes.SemanticKind/Resource` в C++ и `ResolvedPlan.nodes`
  в Python не входят в frozen signature preimage. Выбранный marker-option
  имеет собственный options[i] NodePath, identity local и world random-узла.
  RNG/resolver tags, draws и существующие goldens не изменены.
- Совместимость сцены явно частичная. Корневые controls не реконструируются;
  отсутствие свойства не объявляется доказательством нуля исходного BLK.
  Reached label/require/colors опускаются с NodePath-warning, require
  никогда не исполняется. Prefab требует явного Allow Prefab as Mesh (Lossy).
- Единственный новый diagnostic: **MH_W_DAGOR_CONSTRUCT_DROPPED**; им же
  обозначена разрешённая потеря collision/gameplay-семантики prefab.
  Оба реестра и точные счётчики: **52 E / 15 W**. Новых E-кодов нет.
- Устранена скрытая мутация от чтения lazy PropertyGroup: прямые preflight
  не создают даже пустой mh4blend/dagorprops. Динамический сохранённый
  dagorprops читается и без RNA dag4blend; typed MH-carrier без регистрации
  не игнорируется, а блокирует операцию.
- Warnings/compatibility сохраняются также в partial exception и UI failure
  report, включая предупреждения об уже опубликованном префиксе.
