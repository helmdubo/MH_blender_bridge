## Выполненная часть

- Пустой option с `instance_collection=None` конвертируется в уже существующий
  `RandomOption(kind="empty", weight=N, resource=None)`. Mixed-порядок/веса
  сохранены; все-empty превращается в structural group без entity/selection,
  с сохранением transform/profile/children. Invalid weights по-прежнему отказ.
- Карта logical composite → legacy Collection сохраняется конвертером.
  Перепривязываются только заранее найденные внешние placements рабочей сцены.
  Service scenes, random helpers, MH/legacy definitions защищены независимо
  от того, где они связаны. Membership и исходные pointers ревалидируются
  для всего набора до первой замены; rollback восстанавливает pointers.
- Inline p2 остаётся заблокирован по OPEN-V5-15. Сообщение теперь содержит
  canonical NodePath и явный перечень параметров, а также Blender provenance.
- Новый `dag4blend_publication.py` строит существующий `ClosureExportPlan`
  через реальные FBX/material writers и source inventory. Staging/read-back/
  atomic publication переиспользуются из S4; второго publisher не появилось.
  Порядок: profiles(reuse) → materials → meshes → nested composites → root.
- Явный `publish_dag4blend_composite_collection` проверен скриптом. Только
  успешно опубликованные meshes получают штатные managed stamps. Сами
  mesh Collections/objects/data не заменяются/переименовываются; это явное
  adoption из 13 §1.3, не stamping без writer. Legacy composite/helper
  definitions не штампуются и не правятся. Материализатор получает уже
  опубликованные managed overrides; затем выполняет transactional relink.
- При partial publish остаются точные published/unpublished множества;
  retry работает. Если файловый батч завершён, но Blender finalization упала,
  ошибка честно сообщает весь published набор и `unpublished=[]`; rollback
  файлов не обещается. Shadow manifest/watcher transport не добавлены.
- Ordinary Export Composite/Include All не менялись и скрытой конвертации
  не выполняют. Новых diagnostic codes пока нет: **52 E / 14 W**.

**Новая публикация НЕ подключена к UI.** До решения вопросов и завершения
остатка среза она не является production-ready маршрутом реального CDK.
Существующий conversion UI получил только проверенные empty/relink изменения.
