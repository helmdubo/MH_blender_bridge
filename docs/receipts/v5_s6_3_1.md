# V5-S6.3.1 — тини-транспорт + полевые фиксы дубликации и Ctrl+B

Статус: **реализован, все гейты зелёные**. Дата: 2026-08-30.
Основание: owner «Да, ускорь, я буду щупать тини» (поправка в «Сверке
Lead» дока 12) + первый полевой тест owner (лаг спавна, дубликация,
Ctrl+B). База — S6.3 в той же ветке. Исполнение: субагент (упал на
лимите opus, успел транспортный хелпер + настройку) → доделано Lead.

## Реализовано

1. **Транспорт appearance-каналов** (`MHCompositeAppearanceTransport.h/
   .cpp`, runtime-модуль): 4 канала каждого mesh-листа →
   `SetCustomPrimitiveDataFloat(BaseIndex + c)`; fail-closed окно
   индексов; whole-view вариант отказывает при рассинхроне вида
   (`INDEX_NONE` → полная пересборка). Подключено: (а) компилятор
   превью — каждый лист при сборке; (б) fast-path реролла
   AppearanceSeed — значения обновляются на тех же компонентах без
   пересборки вида; (в) runtime-актор — та же запись при материализации,
   `AppearanceCustomDataBaseIndex` едет свойством, мост резолвит его из
   настроек при handoff (cooked не читает editor-настройки). Настройка
   `AppearanceCustomDataBaseIndex` (default 0) в `MHCompositeSettings`.
   CPD — материализационная сторона, ни в один прообраз не входит.
   Actor-листья не трогаются (ратифицировано).
2. **Меню**: команда **Reseed Appearance** рядом с существующими
   seed-командами (та же транзакционная дисциплина).
3. **Полевой фикс дубликации** (extends S6.2 invariant — flagged
   follow-up квитанции S6.2 п.2): `PostDuplicate`/`PostEditImport`
   больше не строят до регистрации (сборка уходит в единственную точку
   `PostRegisterAllComponents`); `CollectPreviousDerivedComponents` —
   **orphan-union**: previous-вид объединяет отслеживаемые массивы с
   любыми MH-теговыми instance-компонентами актора, сирота усыновляется
   по тегу или ретируется. Самолечит уже сломанные дубликаты при
   следующей пересборке/загрузке. Механизм полевого бага: сборка в
   PostDuplicate до регистрации + сброс transient-массивов текстовым
   реимпортом дубликата → первая сборка становилась невидимыми
   сиротами.
4. **Ctrl+B**: `GetReferencedContentObjects` возвращает
   `UMHCompositeAsset` — штатный Browse to Asset работает.
5. **Версия аддона** 0.6.3 → **0.7.0** (номер не бампался со старых
   срезов и вводил owner в заблуждение; далее бамп на каждую установку).

## Триаж лага спавна (2–3 с)

Двойной «attempting to spawn» в логе — штатный UE (превью-актор при
drag + финальный на drop) → две полные сборки applied-графа на одно
выставление. Обход для превью не городился; причина устраняется
S6.5 shared definition pool (одна сборка замыкания на ассет).
