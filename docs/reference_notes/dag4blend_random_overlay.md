# Референс: dag4blend random custom-properties overlay

Внешний агент прислал overlay-патч к `dag4blend/cmp/cmp_import.py` (owner
передал его как референс, не как зависимость). Изучен статически; в
`reference/dag4blend` НЕ применялся — там лежит нетронутый upstream.

## Что делает патч

При Import Composite, дополнительно к прежнему поведению:

- на Empty каждого `ent{}` вес дублируется из `dagorprops['weight:r']` в
  обычное ID custom property `weight:r` (float);
- родительский Empty узла с вариантами получает `type:t = "random"`
  одновременно в `dagorprops` и в ID custom properties;
- у обычных узлов и вариантов с определённым типом `type:t` тоже зеркалится
  в ID custom properties.

## Проверка round-trip

`reference/dag4blend/cmp/cmp_export.py` содержит `PROPS_TO_SKIP = ["type:t"]`,
поэтому добавленный патчем `dagorprops['type:t']` при обратном экспорте в
`.blk` НЕ пишется. `weight:r` экспортируется только для `ent` и только когда
он не равен 1 — то есть исходное даговское правило «1 по умолчанию не
печатается» сохраняется. Патч round-trip-безопасен.

## Что из этого взято в наш норматив

1. **Приём «typed authority + неавторитетное зеркало в ID custom
   properties»** — 10 §6.4. Позволяет внешним инструментам читать данные, не
   зная внутренностей аддона. У нас тот же паттерн уже был для
   receipts↔Asset Registry tags (§7), поэтому он согласован, а не нов.
2. **Явный маркер random-узла** — как ОДИН из двух признаков распознавания
   при конвертации Dagor→MH (второй, не требующий патча, — helper-коллекция
   `random.*` с ent-Empty внутри).
3. **Правило «нет `weight:r` → ровно 1»** — подтверждено и закреплено.

## Что сознательно НЕ копируется

dag4blend держит варианты в отдельной коллекции внутри служебной сцены и
инстансит её узлом; таким образом веса — source authority — физически живут в
`TECH_STUFF`. У нас `TECH` никогда не является source authority (10 §6.4),
поэтому конвертер поднимает варианты в дети random-Empty. Это единственное
структурное расхождение с референсом, и оно намеренное.

## Статус

Патч на установку художнику НЕ обязателен: конвертация Dagor→MH обязана
работать и на непропатченной dag4blend (через признак helper-коллекции), и
через прямой разбор `.composit.blk`, который остаётся авторитетным путём.
