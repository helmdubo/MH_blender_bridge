# Реестр Dagor phmat (Enlisted) → UE5 PhysicalMaterial

Перенесено из owner-таблицы Enlisted 2026-08-30. Имя phmat — английский
токен, оно же станет именем набора `UPhysicalMaterial`, который owner
создаёт в UE-проекте. Русская колонка — смысл, не идентификатор.

Примечания:

- `barbwire` встречается в двух группах исходной таблицы — токен один.
- Потребитель — V5-S6.1.2 (`docs/15_v5_s6_1_1_hardening.md` §3):
  `*_cls_phys*` → Simple Collision + phmat, `*_cls_trace*` → Complex
  Collision + phmat.
- Неизвестный phmat-токен при импорте — предупреждение и отсутствие
  назначенного PhysicalMaterial, не отказ (реестр может расширяться).
